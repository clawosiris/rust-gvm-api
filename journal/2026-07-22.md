# 2026-07-22 — Debian Service Integration Exposed an Account-Model Decision

## Packaging Direction
- Issue [#373](https://github.com/clawosiris/rust-gvm-api/issues/373) opened after inspection of the published v0.5.0 Debian package confirmed that it installs the gateway binary but no `gvm-gateway.service` unit.
- The proposed work adds a version-controlled systemd unit, package smoke coverage, startup/shutdown documentation, and an explicit install-versus-enable policy so packaged deployments can operate the gateway as a managed service.

## Security Decision
- Implementation now requires choosing between running the gateway as `gvmd` for immediate Unix-socket compatibility or creating a dedicated `gvm-gateway` account with only the group access needed for `/run/gvmd/gvmd.sock`.
- The dedicated account provides the cleaner isolation boundary, while the `gvmd` identity minimizes package-account and socket-permission changes; the choice must be settled before the packaging change merges.
