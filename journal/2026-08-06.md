# 2026-08-06 — API Scope Narrowed as Four Endpoint Proposals Closed

## Product Scope Decisions
- PR [#417](https://github.com/greenbone-hive/rust-gvm-api/pull/417) closed without merge after the team decided that rarely used ticket writes should remain outside the API; the previously accepted ticket-read surface remains.
- PR [#421](https://github.com/greenbone-hive/rust-gvm-api/pull/421) closed without merge because the gvmd trashcan lifecycle is not intended to be exposed through the REST API.
- PR [#424](https://github.com/greenbone-hive/rust-gvm-api/pull/424) closed without merge despite technical approval because report-config CRUD is an advanced, rarely used surface the team does not want to expose for now.
- PR [#425](https://github.com/greenbone-hive/rust-gvm-api/pull/425) was deferred and closed because its timezone catalog requires GMP 22.8 while the currently supported gvmd deployment negotiates GMP 22.7.

## Active Endpoint Work
- PR [#426](https://github.com/greenbone-hive/rust-gvm-api/pull/426) was narrowed after review: scanner and report-format writes were removed as administrative operations, while host, filter, and tag writes remain. Its latest CI is red because `service_report_export_jobs_expire_after_terminal_retention` failed in the stable test job, so it requires attention before merge.
- PR [#418](https://github.com/greenbone-hive/rust-gvm-api/pull/418) replaced generic task and scan-config routing with dedicated, usage-type-scoped audit and policy operations. Its full CI, security, packaging, and REST discovery checks are green, and it remains open for review.
